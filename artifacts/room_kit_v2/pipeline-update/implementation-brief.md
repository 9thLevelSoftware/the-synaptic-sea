## Decisions

- Data definition is consumed by tooling; no per-asset dimension overrides or silent legacy fallback. Invalid/missing policy, unknown modules and unsupported geometry profiles fail explicitly. Ramp remains HOLD. Complex corner/junction/ceiling and portal profiles without enough implemented verification may be HOLD, never falsely PASS.
- APIs in tools/structural_visual_contract.py: VisualContractError(ValueError); load_dimensions(path:Path|None=None)->dict; module_profile(module_id:str, dimensions:dict)->dict; validate_geometry(module_id:str, triangles:Sequence[Sequence[Sequence[float]]], dimensions:dict)->dict. Triangles are positions in actual GLB/Godot Y-up coordinates, not local accessor min/max. Returns {status:'pass'|'fail'|'hold', errors:list[str], measurements:dict, ...}. Empty/nonfinite/degenerate geometry cannot PASS. Helpers and transform identity are additionally checked in the Blender adapter, never inferred from bounds alone.
- module_profile MUST support flat floor_1x1/floor_2x1/corridor_floor_1x1/corridor_floor_1x2, wall_straight_1x1, doorway_frame_open_1x1, pillar_support_1x1. Other IDs are explicit HOLD unless fully supported. It includes family, bounds (min/max), held/reason. Pillar XZ envelope may be bounded, not required filled as a cube; base/top contacts must exist.
- Geometry validation: real envelope, complete floor outer mating faces/bands (no bevel trough), no raised vertices/threshold, no too-deep walkable recess/hole, wall/door terminal band full shared profile, actual triangle/prism doorway intersection including triangles crossing with all vertices outside. Exact designed dimensions with epsilon only numeric round-trip. Never accept AABB extrema alone as proof of a filled mating face.
- tools/validate_structural_visual_fit.py is Blender-compatible adapter + CLI: --project-root ROOT --module ID --glb PATH [--dimensions PATH] [--report PATH]. It uses fresh Blender import, evaluates meshes with full transforms, checks imported helper/light/camera/rig and unbaked scale/pivot, delegates pure geometry. Script entry runs within Blender (--python-exit-code 1); can expose validate_glb(path,module_id,dimensions,bpy)->dict. Report scope is per-module visual/interface validation, explicitly NOT whole-kit/production-assembly acceptance.
- Existing tools/export_structural_glb.py must call fresh reimport validation before replacing any staged output, use canonical policy by default with explicit --project-root/--dimensions support, no disabling flag. Validate all requested variant outputs before publishing any; preserve prior staging on validation failures. Cancellation is a failure, not success-with-no-output. Keep export-only source mutation prohibition.
- tools/promote_structural_sources.py must enforce current source-authority HOLD before any runtime-copy path, including direct promote_module and force/skip-Godot paths; side-effect-free dry-run may report HOLD but never call Blender/copy. Staging export can proceed for validation fixtures; runtime release remains closed. Do not add a way to bypass the hold or claim completed A/B authority integration.
- Preserve the legacy focused-nine recipe implementation in this pipeline-only update. Blanket-blocking authoring unnecessarily disables historical diagnostics. New authoring must follow the shared policy; the mandatory export gate rejects incompatible legacy output. Recipe migration is a separate asset-authoring task, not claimed implemented here.
- Guidelines distinguish fixed physical shell + texture/normal microdetail + geometry within reserved envelope; protected joining strips, actual-camera readability, floor recess-only details, collision/nav ownership, Compatibility Decal limitation, numeric vs visual seams. New automated per-module checks are NOT the future full actual-procgen assembly/variant/collision/render matrix; keep latter as release requirements.
